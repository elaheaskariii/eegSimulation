Multi-Channel EEG Simulation

Synthetic EEG Generation · Computer Vision · Deep Learning · Real-Time Visualization

<p align="center">A Python-based research and engineering prototype for synthetic multi-channel EEG simulation, signal perturbation, webcam-based eye-state detection, and interactive visualization.


📌 Overview

This project is an interactive synthetic EEG simulation prototype that combines signal generation, synthetic neurological-condition perturbation, computer vision, deep-learning architecture, and real-time visualization.

The system generates multi-channel EEG-like signals using mathematical sinusoidal components and Gaussian noise, modifies selected channels according to a synthetic condition model, and visualizes the resulting signals through a Streamlit interface.

A webcam-based MediaPipe Face Mesh component is also used to estimate eye state. When closed eyes are detected, simulated alpha activity is introduced into the occipital channels.

«⚠️ Research / Educational Prototype
The EEG signals generated by this project are synthetic. The system is not a clinical diagnostic tool and has not been clinically validated.»

🧠 EEG Signal Generation

The project generates synthetic EEG-like signals rather than loading physiological recordings.

The signal generator supports up to eight channels:

Fp1
Fp2
T3
T4
O1
O2
P3
P4

For every channel, three frequency components are randomly selected from:

EEG Component| Frequency
Delta| 2 Hz
Theta| 5 Hz
Alpha| 10 Hz
Beta| 20 Hz
Gamma| 40 Hz

The resulting signal is constructed from sinusoidal components plus Gaussian noise.

Mathematical representation

EEG(t) = Σ sin(2π fᵢ t) + N(t)

where:

- "fᵢ" = selected frequency components
- "N(t)" = Gaussian noise

Default signal parameters

Sampling rate : 256 Hz
Duration : 10 seconds
Maximum : 8 channels
Samples : 2560 samples/channel

The sampling relationship is:

10 seconds × 256 samples/second = 2560 samples

🧬 Synthetic Disorder Simulation

The function:

apply_disorder()

is responsible for applying condition-specific modifications to the generated EEG signal.

Current implementation

Only Epilepsy currently contains an implemented signal perturbation.

Affected channels:

T3
T4

A periodic amplitude perturbation is introduced into these channels.

«Important: This is a mathematical perturbation used for simulation and demonstration. It is not a validated physiological model of epilepsy.»

---

🎥 Motion Artifact Simulation

The prototype includes a simplified model of frontal signal artifacts.

With an approximate probability of 10%, additional Gaussian noise is introduced into:

Fp1
Fp2

This is intended to represent a simplified example of frontal EEG contamination associated with facial movement.

The artifact model is stochastic and is not based on measured EEG artifact recordings.

🤖 GAN Architecture

A preliminary Generative Adversarial Network (GAN) architecture is included in the codebase.

Generator

The generator receives a 100-dimensional latent vector.

Latent Vector
     │
     ▼
Dense(256)
     │
     ▼
Dense(512)
     │
     ▼
Dense(3 × 256)
     │
     ▼
Reshape
     │
     ▼
(3, 256)

Discriminator

The discriminator receives:

Input Shape: (3, 256)

and processes it through:

Input
  │
  ▼
Flatten
  │
  ▼
Dense(256)
  │
  ▼
Dense(1, sigmoid)

The architecture uses:

Optimizer : Adam
Loss : Binary Cross-Entropy

Current GAN status

The GAN is currently an architectural prototype.

The current project does not contain:

- Real EEG training data
- GAN training loop
- Trained generator weights
- Generated-sample evaluation
- Quantitative GAN performance metrics

Therefore, the GAN is currently a foundation for future development rather than the active EEG generation mechanism.

🔬 Reproducibility

The EEG generator contains stochastic operations including:

- Random frequency selection
- Gaussian noise generation
- Random artifact generation

Therefore, different executions may produce different synthetic signals.

For deterministic experiments, a fixed random seed can be introduced in a future version.

Example:

np.random.seed(42)

⚠️ Limitations

Synthetic EEG

The generated signals are mathematical simulations and are not recordings from human subjects.

Simplified Physiology

The current signal model does not reproduce the complete physiological complexity of real EEG.

Condition Models

Only the epilepsy option currently modifies the signal. Other conditions are currently placeholders.

No Clinical Validation

The system has not undergone clinical validation and must not be used for diagnosis or medical decision-making.

Simplified Eye Detection

Eye state is estimated using selected facial landmarks and a fixed threshold. Performance may be affected by:

- Lighting
- Camera position
- Face orientation
- Individual facial characteristics

Simplified Artifact Model

Facial artifacts are represented using randomly generated noise rather than measured EEG artifacts.

GAN Status

The GAN architecture is defined, but the current project does not contain a complete training pipeline or trained model weights.

Stochastic Output

Because random components are used during signal generation, different executions can produce different signals.
